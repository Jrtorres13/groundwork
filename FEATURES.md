# Groundwork: features

- **Today screen:** weekly plan, streak, week tracker, stats, skill levels
- **Guided workout player:** big countdown ring, rep logger, auto rest timers, beeps, optional voice coach, pause/back/skip, keeps screen awake
- **8 skill ladders, 42 progressions:** auto double progression (3x5 → 3x8 → next step)
- **8 workouts:** Full-Body Strength, Upper Body Power, Legs & Hinge, Daily Joint CARs, Deep Mobility, Fascia Flow, Desk Reset, Core & Skills
- **Custom workout builder:** pick exercises, sets, reps/secs, rest
- **Library:** 70+ exercises, 7 categories, search, how-to cues, demo video link
- **Progress:** 16-week heatmap, totals, training mix, history
- **Learn:** 8 research cards + sources (see RESEARCH.md)
- **Settings:** light/dark, sound, voice, rest length, level reset, backup/restore
- Works offline. Data stays on the PC.
