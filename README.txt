GROUNDWORK - calisthenics, mobility and fascia trainer
=====================================================

INSTALL (Windows 10/11, about 1 minute)
1. Unzip this folder anywhere.
2. Double-click Install.bat
   (If Windows says "protected your PC": More info > Run anyway.)
3. Done. It opens now. Shortcuts are on your Desktop and Start Menu.

FIRST TIME
- Pick your level: Beginner, Intermediate or Advanced.

DAILY USE
- Today: your plan for the day. Press the big orange button.
    Mon/Wed/Fri = Full-Body Strength   Tue = Fascia Flow
    Thu = Deep Mobility   Sat = Core & Skills   Sun = Rest + CARs
- Daily 6-minute CARs: slow joint circles. Best daily habit.
- In a workout:
    Reps: tap + / - to log what you did, then "Done set".
    Holds: "Start hold", the ring counts down, it beeps at the end.
    Rest timers start on their own. Space = next, Esc = end.
- Skills: 8 ladders (push-up, dip, pull-up, row, squat, hinge,
  core, handstand). Start 3 x 5, add a rep each session.
  At 3 x 8 you get a "Level up" button.
- Workouts: 8 ready-made plans + "Build your own".
- Library: 70+ exercises with steps and a "Watch a demo" link.
- Learn: the research, in short cards.

PRIVACY
- Everything is saved only on this PC (%LOCALAPPDATA%\Groundwork).
- Settings > Back up my data gives a code. Paste it on your phone to move data.

UPDATE: unzip the new version and run Install.bat again. Your data stays.
REMOVE: run Uninstall.bat.
